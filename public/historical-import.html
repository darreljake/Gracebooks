🕰️ Historical Data

What this is

Historical records never touch current balances. Imported figures live only in the historicalMonthly and historicalAnnual collections and are used only for trend and comparison displays (Council Dashboard, Reports year-over-year chart). They are never written to income, expenses, budgets or beginning balances, so Financial Overview, cash levels, the Print Report and every live balance are unaffected.
Upload the prepared GraceBooks-Historical-Import.xlsx: a Monthly Ledger sheet with the columns Year, Month, Period, Direction, Category, Subcategory, Category Key, Fund, Amount, Source Label, Source File (and optionally Pass Through, Note). The file is read in this browser; its contents go nowhere except to Firestore when you press Import. Donor names are never imported: a Donor Giving sheet, if present, is ignored.
