🧾 Receipt Recovery

Find lost liquidation receipts

This page looks for receipt files that are still in storage but no longer linked to a liquidation request or an expense, and for linked receipts whose file is gone. It checks the current requests and expenses, the Audit Log (every receipt upload, deleted request and replaced receipt is recorded there) and the storage folders themselves. Nothing is ever deleted here. Every re-link, restore or re-upload is written to the Audit Log.

Files in storage that are not linked anywhere

These files exist but no request or expense points to them, so they show up nowhere in the app. Re-link one to its request, restore a deleted request, or attach it to an expense.

Linked receipts whose file is gone

A request or expense still points to these, but the file is no longer in storage. If you still have the paper receipt or the photo, upload it again here. The new file takes the old one's place, so links to liquidation items stay intact.

Receipts that are there but not shown in reports

The receipts are still on the request, but some items are not matched to a receipt, so their expenses show "No receipt" in the Print Report and Supporting Documents. Open Liquidation & Reimbursements and use 🔗 Match Receipts on these requests.
